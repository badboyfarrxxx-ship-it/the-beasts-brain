### What's Still In Progress

- **Boot the second computer from the stick and install.** Keep it offline or set the
  connection metered, because a 21H2 image will pull several GB of catch-up updates the
  moment it gets online.
- **The stick is UEFI-only.** Copying files writes no MBR boot sector. If that machine is
  BIOS-only or stuck in CSM, the stick will not show in its boot menu and it has to be
  redone with Rufus.
- Check whether the target machine's network adapter is covered by in-box drivers before
  wiping it. Without a network there is no way to fetch drivers afterwards.

### Decisions Made

- **Not rebuilding for a smaller ISO.** At 4.79 GB it is bigger than tiny11's advertised
  ~3.5 GB, because this release exports `install.wim` at max compression instead of
  converting to `install.esd`. Shrinking it means an elevated `/compress:recovery` re-export
  and another long DISM pass for no practical benefit. The only real consequence is that
  `install.wim` at 4.11 GB exceeds the FAT32 file limit, which Rufus handles on its own.
- **Renamed the broken ISO folder instead of deleting it.** Deleting is Nathan's call; the
  name is enough of a guard in the meantime.
- **Wrote the stick by hand rather than handing Rufus back to Nathan.** Rufus would have
  meant him doing the job at the keyboard while The Beast watched. Copy plus split reaches
  the same result, is fully scriptable, and the only thing it gives up is legacy BIOS boot,
  which was never part of the plan (the instructions have always said UEFI, non CSM).
